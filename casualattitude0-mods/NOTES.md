# Mod 開發筆記

寫這個資料夾底下的 Claude Code mod 時要遵守的規則。每條都來自實際踩過的坑。

## 版面

### 桌面版的寬度用比例，不用字元格數

會在桌面版顯示的版面，寬度用比例（`width="50%"`）和 `flexGrow` 讓畫面自己分配。
`e.props.bodyColumns` 這類字元格數只用在終端機。

桌面版的字不是等寬格子，用格數算出來的寬度一定不準。量測值不準時換方法，不要乘修正係數。

### 版面改動要看過實際畫面才算完成

`claude plugin test` 只檢查元件結構，不檢查畫出來的樣子；測試全過不代表版面正確。
版面類改動在看過實際畫面（截圖）之前，不能當作完成。

### 變窄時要隱藏什麼，先確認必留欄位

做自適應寬度前，先確認哪些欄位必須永遠顯示，再決定隱藏順序。
`session-board` 的剩餘時間就是必留欄位：任何寬度都要顯示。

## 來源

2026-10-08 復盤 `usage-bar` / `session-board` 的 RWD 實作，來回改了四輪：

1. 用字元格數設寬度門檻，桌面版只是近似。
2. 用格數算左右各半與進度條長度，進度條衝出右邊界。
3. 乘上從截圖量出的 1.7 倍修正，右邊留下大片空白。
4. 改成左右各 50%、進度條自動撐滿，問題解決。

四輪都是在沒看過實際畫面的情況下交付的；第一輪自行決定「太窄時隱藏剩餘時間」，第四輪才被糾正。
