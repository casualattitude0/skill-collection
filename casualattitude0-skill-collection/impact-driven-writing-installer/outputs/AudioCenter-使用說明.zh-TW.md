# AudioCenter 使用說明（給企劃／美術）

一套輕量的 Unity 音訊系統。它把整個專案的聲音播放集中到一個管理者身上，讓你不必在每個場景、每個物件上各自處理 AudioSource。你可以播放**背景音樂、音效、UI 音效**三種聲音，分別調整音量與靜音；可以做淡入淡出、分層音樂、按步驟排好的音訊演出，還有一套把音檔整理成命名群組的編輯器視窗——**這些大多不必寫程式，光靠 Inspector 拉設定就能完成**，讓企劃與美術也能自行管理聲音。

> 這份說明的目標讀者是不寫程式的企劃與美術。文中幾乎不出現程式碼，所有功能都會告訴你「在編輯器裡怎麼做」與「這個功能是拿來幹嘛的」。少數需要工程師協助的地方會特別標註。

以下逐項說明每個功能的用途與使用方式。

---

## 先看懂：一個管理者、三條音軌、四個音量

**一個管理者（AudioCenterAudioManager）。** 整個遊戲只需要一個。它住在啟動場景的某個 GameObject 上，負責播放所有聲音，而且**換場景時不會被銷毀**，所以背景音樂不會在切場景時斷掉。

**三條音軌（Track）：** 每個聲音都歸在其中一條——

- **背景音樂（BGM）** — 場景或關卡的主旋律。同一時間只會有一首在播，換音樂時自動接手原本那條，不會疊在一起。
- **音效（SFX）** — 爆炸、腳步、撞擊、提示音等遊戲世界裡的一次性短音。可以很多個同時播。
- **UI 音效（UI）** — 按鈕點擊、選單切換、彈窗等介面音。和 SFX 分開，方便你單獨控制介面音量。

**四個音量匯流排（Bus）：** **Master（總音量）、BGM、SFX、UI**。每條音軌的實際大小是「自己那條的音量 × Master 音量」。

**用途：** 把聲音分軌、分匯流排最大的好處，是玩家可以在設定畫面分別控制。例如有人想關掉背景音樂但保留音效，或把 UI 音壓低、遊戲音效調大，這個系統天生就支援。

## 兩種指定音檔的方式

要播一段聲音，有兩種指定來源的做法，可以混用：

1. **用名稱查表（Library，預設）** — 先把音檔整理進「音效庫」（見下方〈編輯器工具〉），之後只要給「群組名稱 ＋ 音效名稱」就能播，例如群組 `UI` 裡的 `Click`。
2. **直接指定音檔（File）** — 把音檔本身（AudioClip）拉進對應欄位。適合一次性、單獨使用的聲音。

**用途：** 名稱查表的好處是解耦——物件上只記住名字，實際音檔在音效庫統一管理。日後要換音效或調內容，只要在音效庫裡換掉，不必逐一去每個用到的地方重拉。專案越大、聲音越多，這個方式越省事。**建議優先用名稱查表**，File 只留給不值得進庫的一次性音檔。

> **注意：** 用名稱查表時若名字打錯或庫裡找不到，**播音效會安靜略過**（不出聲、不報錯），**播背景音樂則會直接出錯**。所以使用名稱播放前，務必確認群組與名稱拼寫一致（**區分大小寫**）。

## 背景音樂的各種操作

背景音樂除了播放與停止，還有一整套銜接與過場用的操作：

- **播放** — 開始播一首，並可選擇是否循環（一般背景音樂會設循環）。播新的會自動接手換掉舊的。
- **停止** — 完全停止並回到開頭。
- **暫停／恢復** — 暫停會記住播到哪裡，恢復時從原位置繼續，並可選擇是否「淡入」回來（聲音由小漸大，比突然出現柔順）。
- **淡入** — 從無聲漸漸放大到正常音量，常用在關卡開場。
- **淡出** — 漸漸變小到無聲，常用在關卡結束或進過場。淡入與淡出若互相打斷，系統會自動接手，不會出現兩段淡化打架。
- **BGM 閃避（Ducking）** — 暫時把背景音樂壓低一截（例如旁白或重要語音響起時讓人聲更清楚），事後再放回原本大小。這是疊在音量上的暫時調整，**不會覆寫玩家自己的音量設定**。

**取得播放進度：** 系統可以讀到背景音樂目前播到第幾秒，這在「讓某個音效對齊音樂節拍」時很有用（見下方〈對齊背景音樂播放〉）。

## 音效與 UI 音效的播放

播放音效時，除了指定音檔，還有幾個可調整的細節：

- **是否循環** — 適合持續性的環境音（風聲、機器運轉聲）。
- **走哪條音軌** — 同一個播放方式可以指定算成「音效（SFX）」還是「UI」，以套用對應匯流排的音量與靜音。預設是 SFX；介面音請選 UI。
- **隨機音高（Rnd Pitch）** — 開啟後，每次播放會在你設定的範圍內隨機微調音高。**用途：** 像腳步聲、撞擊聲這類密集重複的音效，加一點隨機音高能避免聽起來像複製貼上的機械音，讓重複的聲音更自然。範圍常設成例如 −0.3 到 0.3。

**停止控制：** 可以停掉某一個特定的聲音，或一次停掉所有正在播放的音效（例如切場景、進暫停選單時）。

**自動清理：** 系統用一個「音源池」來播聲音——預先準備好一批播放器（預設 10 個），輪流重複使用，播完自動回收，你不必手動清理。池子用完時預設會自動擴充。**唯一要留意的是：** 在極短時間內密集播放大量音效時，效能敏感的場合可斟酌池子大小。

## 播放模式：同名聲音重複播放時的處理

當你要播的聲音，和一個「同名、還在播放中」的聲音撞名時，有三種處理方式：

- **重播（預設，ReplayIfExisted）** — 先把舊的停掉，再從頭重新播。適合 UI 點擊音這種「每次都該重來」的聲音。
- **若已在播則忽略（IgnoreIfExisted）** — 維持舊的繼續播，這次請求不做事。適合不希望被打斷的聲音。
- **允許多個同時播（AllowMultiple）** — 不管舊的，再開一個疊著一起播。適合可重疊的音效，例如連續射擊、多顆金幣同時掉落。

選對播放模式，能避免「狂點按鈕時聲音破音重疊」或「重要聲音被自己蓋掉」這類常見問題。

## 不用寫程式：Audio Action 觸發器

如果你不想寫程式，靠 Inspector 就能觸發聲音。做法是把 **`AudioCenterAudioController`** 元件掛到任何一個 GameObject 上（在 **Add Component → AudioCenter** 選單裡找得到），然後在它的 **Audio Action** 欄位設定「這次要做什麼動作」。

**這個動作能設定的內容包括：**

- **要操作的對象** — 背景音樂，或音效。
- **背景音樂的動作** — 播放、停止、暫停、恢復、淡入、淡出。
- **音效的動作** — 播放、停止、全部停止、對齊背景音樂播放（AttachOnBGM）。
- **音檔來源** — 名稱查表（Library）或直接拉音檔（File）。
- **其他細節** — 走哪條音軌、是否循環、播放模式、是否隨機音高等。Inspector 會聰明地只顯示和你目前選擇相關的欄位，不會把所有選項全攤出來讓你眼花。

**怎麼觸發這個動作：**

- **開場自動執行** — 勾選 **Action On Start**，物件一啟用就自動跑。適合「進場景就播背景音樂」。
- **由事件觸發** — 把這個元件的 **DoAction()** 掛到任何 UnityEvent 上，例如 UI 按鈕的 OnClick、動畫事件、Timeline 的 signal。如此一來，企劃或美術不必碰程式，就能把聲音接到互動上。

### 對齊背景音樂播放（AttachOnBGM）

音效動作裡有一個特別選項：**對齊背景音樂播放**。它會以背景音樂目前播到的時間點為起始位置來播這段音效。**用途：** 想讓某個聲音和音樂的節拍同步出現（配合鼓點、節奏遊戲的提示音、與現有曲子對齊製作的分軌）時，用這個就能讓音效對上音樂進度，而不是各播各的。

## 環境音：隨機間隔播隨機聲音

把 **`AudioCenterAmbientAudio`** 元件掛上去，它會以**隨機的時間間隔**，從你給的一份候選清單裡**隨機挑一個**來播。

| 設定 | 說明 |
|---|---|
| Audio Pool | 候選的聲音清單（每筆都是一個 Audio Action） |
| Repeat Interval | 兩次播放之間的最短／最長秒數（預設 3–8 秒） |

**用途：** 製造不規律的環境氣氛——例如「每隔 3 到 8 秒隨機傳來一聲鳥叫或蟲鳴」，比固定間隔的同一聲自然得多。它不會自動開始，需要由你觸發開始；也提供「立刻隨機播一次」與「停止循環」的操作，方便進出某個區域時開關。

---

## 音量滑桿綁定：設定畫面的捷徑

把 **`AudioCenterAudioSettings`** 元件掛在設定面板上，指定 **Music / Sfx / Ui** 三根音量滑桿。遊戲開始時，它會自動把滑桿的位置同步成目前的音量值，並自動接好「拖動滑桿就改音量」的連動——**不必手動接事件**。玩家拖動時即時生效，正在播放中的聲音也會立刻跟著變大或變小，不需要重播。

---

## 分層音樂（MusicMixer）：讓音樂隨情境疊加

**`AudioCenterMusicMixer`** 適合「同一首曲子、隨遊戲狀態加減層次」的音樂設計。它有一條**永遠在播的基底（Main Bgm）**，上面可以疊加可切換的**圖層（Layers）**，例如：基底是和弦鋪底，戰鬥時加進鼓組層、危急時再加進弦樂層。

它最關鍵的特性是**相位鎖定**：所有圖層都對齊同一個時間軸循環，切換圖層時**只交叉淡化音量、時間軸永不重啟**，所以層與層之間永遠是同步、對拍的。

| 設定 | 說明 |
|---|---|
| Main Bgm | 永遠播放的基底音樂 |
| Bed Volume | 有圖層啟用時，基底的音量 |
| Bed Only Volume | 「只有基底」（例如主畫面）時的基底音量 |
| Layers | 各圖層清單（名稱、音檔、音量） |
| Start Layer | 開始播時要啟用的圖層（設 −1 = 只有基底） |
| Play On Start | 自動開始（預設開啟） |
| Crossfade Duration | 切換圖層時的交叉淡化秒數（0 = 直接切） |

切換圖層、回到「只有基底」的主畫面狀態、靜音所有圖層、下一個／上一個圖層，都能由 UnityEvent 觸發，一樣不必寫程式。

> **重要限制：** 所有圖層音檔必須是**同一段循環的分軌**——長度、速度（BPM）要和基底完全相同。長度不一樣的音檔會在循環邊界慢慢跑掉拍子。這是製作素材時就要守住的規則。

---

## 音訊序列器（Sequencer）：把一段聲音演出排成清單

**`AudioCenterAudioSequencer`** 讓你像排清單一樣，把一連串聲音動作**按順序排好**，整段一次播出——**完全不必寫程式**。適合過場、開場演出、教學引導這種「先做這個、等兩秒、再淡入那個」的編排。

每一個步驟可以是這幾類：

- **BGM** — 播放、停止、暫停、恢復、淡入、淡出。
- **音效（Sound）** — 播放、停止、全部停止。
- **音量（Volume）** — 設定、靜音、淡化（指定某個匯流排）。
- **流程（Flow）** — 等待幾秒、等背景音樂播完才繼續、BGM 閃避／取消閃避、觸發一個事件（UnityEvent，可用來連動畫面、字幕、特效等）。

每個步驟都有這些共用設定：

- **Label** — 顯示名稱，方便你看懂這步在做什麼。
- **Active** — 取消勾選就跳過這步（方便暫時關掉測試）。
- **Initial Delay** — 執行前先等幾秒。
- **Wait For Completion** — 勾選的話，會等這步做完（例如淡化結束）才進下一步；不勾就「射後不理」、立刻接著下一步。

也可以設定整段 **Loop（播完從頭再來）** 與 **Play On Start（進場景自動播）**。

> **注意：** 中途停止序列只會停下排程，不會自動還原已經發出的聲音或淡化。需要乾淨收尾的話，請在清單最後自己加上明確的「停止／淡出」步驟。

## UI 自訂按鈕（Custom Button）：會彈跳又會出聲的按鈕

**`AudioCenterCustomButton`** 是一個加強版的 UGUI 按鈕：滑鼠移上去和點擊時會有**彈跳縮放動畫**，並在點擊時自動播放一個 UI 音效。換句話說，按鈕的「手感」和「音效」一次搞定。

**動畫怎麼調：** 動畫的參數放在一個叫 **Button Animation Config** 的設定檔裡，多顆按鈕可以共用同一組預設，調一次全部一起變。

> **重要：請在 `Assets/` 底下建立自己的設定檔，不要建在套件資料夾內。**
> 建在 `Assets/Plugins/AudioCenter/` 裡的東西，套件更新或重裝時會被**覆蓋或遺失**。請在你自己的專案資料夾（例如 `Assets/Settings/`）裡，用 **Create → AudioCenter/UI/Button Animation Config** 建立，再指派到按鈕上。沒指派設定檔的按鈕仍然能用，會退回內建的預設動畫值。

**批次設定一整批按鈕：** 打開主選單 **AudioCenter → Custom Button Tool**，選一個掃描範圍（單一物件／目前場景／所有已載入場景），指派好設定檔與要播的 UI 音效，再按 **Add Custom Buttons**，就會一次幫範圍內的按鈕都裝上。新增與移除都支援復原（Undo），按錯不怕。

## 編輯器工具：管理音效庫

這套工具讓你把專案裡的音檔整理成命名群組，之後就能用名稱來播放（見上方〈兩種指定音檔的方式〉）。

### Audio Library 視窗

選單位置：**AudioCenter → Audio Library**。

這是一個左右雙面板的視窗：

- **左面板** 列出所有群組（例如 `BGM`、`SFX`、`UI`、`Enemy`）。
- **右面板** 編輯目前選到的群組裡的音效——每一筆是「自訂名稱 ＋ 對應音檔」的配對。

你在這裡建立群組、加入音檔、替每個音檔取一個好記的名字，這些名字就是日後播放時要用的「音效名稱」。工具列可切換目前在編輯哪一個音效庫資產；群組可改名、刪除，音效列支援多選刪除。

### Audio Action 欄位

凡是要設定一個聲音動作的地方（觸發器、序列器步驟），Inspector 都會用同一套「逐層展開」的介面：先選 BGM 或 Sound → 選動作 → 選 File 或 Library → 選 Library 時會自動跳出群組／音效的下拉選單（直接讀你專案裡的音效庫）。**它只顯示和你目前選擇相關的欄位**，不會一次塞給你所有選項。

### 序列器 Inspector

序列器的步驟清單可以**拖曳排序**，**+** 下拉選單按分類分組讓你挑步驟類型，每一步可展開／收合。進入 Play 模式測試時，正在執行的那一步會以綠色高亮，面板底部還有 Play／Stop 按鈕方便你直接試。

## 資產：兩個要先建立的檔案

AudioCenter 有兩個用「右鍵 → Create」建立的設定檔，是整套系統的基礎：

### 音效庫（Clip Library）

**Create → AudioCenter → Audio → Clip Library。** 一個檔案裡裝著具名群組，每個群組存放「名稱 → 音檔」的對應，例如：

```
音效庫
├─ BGM： MainMenu → 主選單.mp3、 Battle → 戰鬥.mp3 …
├─ SFX： Click → 點擊.wav …
└─ UI：  …
```

### 遊戲設定（Game Settings）

**Create → AudioCenter → Audio → Game Settings。** 管理者啟動時讀一次，決定初始狀態：

| 設定 | 預設 | 說明 |
|---|---|---|
| 各匯流排預設音量（Master／Music／Sfx／UI） | 1 / 0.8 / 1 / 1 | 初始音量 |
| Start Muted | 關 | 啟動時是否全部靜音 |
| Pool Size | 10 | 預先準備幾個播放器 |
| Pool Can Expand | 開 | 不夠用時是否自動擴充 |

## 安裝與初次設定

1. **放一個管理者。** 在啟動場景的某個 GameObject 上加 **`AudioCenterAudioManager`** 元件，並指定它要用的 **Library（音效庫）** 與 **Default Settings（遊戲設定）** 兩個資產。它會跨場景存活，整個遊戲只會有一個。
   > 系統在找不到管理者時雖然會自動生一個臨時的，但那個**沒有指定音效庫**，名稱查表會失效——所以請務必在啟動場景手動放好。
2. **建立並填好音效庫。** 用上面的 Audio Library 視窗建群組、加音檔、取名字。
3. **建立遊戲設定。** 設定初始音量與音源池大小，指派給管理者。
4. **開始用。** 之後就能用觸發器、序列器、自訂按鈕等不寫程式的方式接聲音了。

---

## 使用前的注意事項

- **管理者要手動放在啟動場景。** 自動生成的臨時管理者沒有音效庫，名稱查表會找不到聲音。
- **名稱查表打錯時的行為不一致。** 播音效找不到會**安靜略過**（不出聲、不報錯）；播背景音樂找不到會**直接出錯**。名稱與群組要拼對，且**區分大小寫**。
- **分層音樂的素材必須同拍同長。** MusicMixer 的每個圖層都要和基底是同一段循環的分軌（長度、BPM 一致），否則會逐漸跑拍。
- **按鈕動畫設定檔要建在 `Assets/` 底下，別建在套件資料夾內**，否則更新套件時會被覆蓋遺失。
- **音效是「即時借用、播完歸還」。** 一般使用完全不必擔心；只有在極短時間內密集播放大量音效時，效能吃緊的場合要留意音源池大小。
- **停止序列器不會自動收尾。** 中途停止不會還原已播出的聲音與淡化，需要的話請在清單裡自己加停止／淡出步驟。

## 給工程師的一句話

以上功能也都能用程式呼叫——所有 API 都是 `AudioCenter` 命名空間下 `AudioCenterAudioManager` 的靜態方法（`PlayBGM`、`PlaySound`、`FadeOutBgm`、`SetBusVolume`、`GetAudioSettings`／`SetAudioSettings` 存讀設定等）。完整 API 與參數請看套件內的 **Documentation.zh-TW.md**（官方文件）。
