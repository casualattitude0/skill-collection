# CustomAudio 使用說明

一套輕量的 Unity 音訊系統。它把整個專案的聲音播放集中到一個管理者身上，讓你不必在每個場景、每個物件上各自處理 AudioSource。你可以播放背景音樂、音效與語音三種聲音，分別調整音量與靜音，並把這些設定自動保存下來；既能在程式裡呼叫，也能完全靠 Inspector 拉設定來觸發，搭配把音檔整理成命名群組的編輯器視窗，讓美術與企劃也能自行管理聲音。

以下逐項說明每個功能的用途與使用方式。

---

## 三個聲道：背景音樂、音效、語音

系統把所有聲音分成三條獨立的聲道：

- **背景音樂（BGM）** — 場景或關卡的主旋律。同一時間只會有一首背景音樂在播放，換音樂時會接手原本的那一條，不會疊在一起。
- **音效（Sound / SFX）** — 按鈕點擊、爆炸、腳步、提示音等一次性短音。可以同時有很多個音效在播。
- **語音（Vocal）** — 角色台詞、旁白等。和音效分開管理，方便你單獨調整人聲大小，例如「語音保持清楚、音效壓低一點」。

**用途：** 把聲音分成三類最大的好處，是玩家可以在設定畫面分別控制這三條的音量與靜音。例如有些玩家想關掉背景音樂但保留語音，或把音效調小、語音調大，這個系統天生就支援這種需求。

---

## 音量與靜音的設定與保存

每一條聲道都有各自的音量（從 0 到 1，0 是全靜音、1 是最大）與靜音開關。你可以：

- **分別調整三條聲道的音量** — 通常接到設定選單裡的三根滑桿上，玩家拖動時即時生效，正在播放中的聲音也會立刻跟著變大或變小，不需要重播。
- **分別切換三條聲道的靜音** — 靜音和音量是獨立的兩件事；靜音時音量數值仍然保留，解除靜音後就回到原本的大小，不會被歸零。
- **一次套用一整組設定** — 例如載入一份玩家偏好設定時，可以一口氣把三條聲道的音量與靜音狀態整批更新。

**自動保存：** 所有音量與靜音的變更都會立刻寫入 Unity 的玩家偏好設定（PlayerPrefs）並存檔，因此玩家下次開遊戲時會自動還原上次的設定，你不需要自己另外做存檔流程。

**設定可隨時讀取：** 即使聲音管理者還沒在場景中建立起來（例如還停在最開頭的標題畫面），你仍然讀得到目前的音量與靜音值——這時它會直接從保存的偏好設定讀取，所以設定畫面在任何時間點顯示的數字都會是正確的。

## 兩種指定音檔的方式

要播一段聲音，有兩種指定來源的做法，可以混用：

1. **直接指定音檔** — 把音檔本身（AudioClip）拉進對應欄位。適合一次性、單獨使用的聲音，最直接。
2. **用名稱查表** — 先把音檔整理進「音檔庫」（見下方〈編輯器工具〉），之後只要給「群組名稱 + 音檔名稱」就能播放，例如群組 `UI` 裡的 `Click`。

**用途：** 名稱查表的好處是解耦——程式或物件上只記住名字，實際的音檔放在音檔庫統一管理。日後要換音效、調整內容，只要在音檔庫裡換掉，不必逐一去每個用到的地方重新拉參考。專案越大、聲音越多，這個方式越省事。

> **注意：** 用名稱查表播放音效時，若名字打錯或音檔庫裡找不到，系統會安靜地略過、不發出聲音也不報錯；播放背景音樂時則相反，找不到會直接出錯。所以使用名稱查表時，務必確認群組與音檔名稱拼寫正確。

## 背景音樂的各種操作

背景音樂除了單純的播放與停止，還支援一整套銜接與過場用的操作：

- **播放** — 開始播一首背景音樂，並可選擇是否循環（一般背景音樂會設成循環）。播放新的背景音樂會接手原本那條，自動換掉。
- **停止** — 完全停止背景音樂並回到開頭。
- **暫停** — 在目前位置停住，記住播到哪裡。
- **恢復** — 從暫停的位置繼續播，並可選擇是否「淡入」恢復（聲音由小漸大地回來，比突然出現更柔順），以及淡入要花幾秒。
- **淡入** — 讓背景音樂從無聲漸漸放大到正常音量，常用在關卡開場。
- **淡出** — 讓背景音樂漸漸變小到無聲，常用在關卡結束或進入過場。淡出與淡入之間若互相打斷，系統會自動接手，不會出現兩段淡化打架的狀況。

**取得播放進度：** 你可以讀到背景音樂目前播到第幾秒，這在「讓某個音效對齊音樂節拍」時很有用（見下方的「對齊背景音樂播放」）。

## 音效與語音的播放

播放音效或語音時，除了指定音檔，還有幾個可調整的細節：

- **是否循環** — 適合持續性的環境音（例如風聲、機器運轉聲）。
- **起始位置** — 可以指定從音檔的第幾秒開始播，而不是一定從頭。
- **隨機音高** — 開啟後，每次播放會在你設定的範圍內隨機微調音高。**用途：** 像腳步聲、撞擊聲這類會密集重複的音效，加一點隨機音高能避免聽起來像複製貼上的機械音，讓重複的聲音更自然。
- **指定走音效或語音聲道** — 同一個播放方式可以選擇要把這段聲音算成「音效」還是「語音」，以套用對應聲道的音量與靜音。

**停止控制：** 你可以依名稱停掉某一個特定的聲音，或一次停掉所有正在播放的音效與語音（例如切換場景、進入暫停選單時）。也可以查詢某個聲音現在是否還在播放。

**自動清理：** 每播一個音效，系統會在背景幫它建立播放來源，播完之後自動回收，你不需要手動清理。唯一要留意的是：如果在極短時間內密集播放大量一次性音效，這種「建立後回收」的動作會很頻繁，效能敏感的場合要斟酌。

## 播放模式：同名聲音重複播放時的處理

當你要播的聲音，和一個「同名、還在播放中」的聲音撞名時，有三種處理方式可選：

- **重播（預設）** — 先把舊的那個停掉，再從頭重新播放。適合 UI 點擊音這種「每次都該重來」的聲音。
- **若已在播則忽略** — 維持舊的繼續播，這次的播放請求不做任何事。適合不希望被打斷的聲音，例如某段正在播的語音。
- **允許多個同時播** — 不管舊的，再開一個新的疊著一起播。適合可以重疊的音效，例如連續射擊、多顆金幣同時掉落的聲音。

選對播放模式，能避免「狂點按鈕時聲音破音重疊」或「重要語音被自己蓋掉」這類常見問題。

## 用 Inspector 設定播放：Audio API 元件

如果你不想寫程式，也能完全靠 Inspector 來觸發聲音。做法是把 **`0 : Tools/Audio/Audio API`** 這個元件掛到任何一個 GameObject 上，然後在它的欄位裡設定「這次要做什麼動作」。

**這個元件能設定的內容包括：**

- **要操作的對象** — 背景音樂，或音效。
- **背景音樂的動作** — 播放、停止、暫停、恢復、淡入、淡出（與上方〈背景音樂的各種操作〉一致）。
- **音效的動作** — 播放、停止、全部停止、對齊背景音樂播放。
- **音檔來源** — 選擇直接拉一個音檔，或用群組名稱＋音檔名稱查表。
- **其他細節** — 是否循環、恢復時是否淡入、淡化秒數（0 到 10 秒）、播放模式、是否隨機音高與其範圍等。Inspector 會聰明地只顯示和你目前選擇相關的欄位，不會把所有選項全攤出來讓你眼花。

**怎麼觸發這個動作：**

- **開場自動執行** — 勾選「開始時執行」，物件一啟用就會自動跑這個動作。適合「進場景就播背景音樂」這種需求。
- **由事件觸發** — 把這個元件的「執行動作」掛到任何 UnityEvent 上，例如 UI 按鈕的點擊、動畫播放到某一格的動畫事件、Timeline 的 signal 等。如此一來，企劃或美術不必碰程式，就能在編輯器裡把聲音接到互動上。

### 對齊背景音樂播放

音效動作裡有一個特別的選項：「對齊背景音樂播放」。它會以背景音樂目前播到的時間點為起始位置來播放這段音效。**用途：** 想讓某個聲音和音樂的節拍同步出現（例如配合鼓點、節奏遊戲的提示音）時，用這個就能讓音效對上音樂的進度，而不是各播各的。

## 輔助元件

這兩個元件是建立在 Audio API 元件之上的便利工具，同樣不需要寫程式。

### 隨機播放：Random Audio API

元件選單位置：**`0 : SOB/APIs/Random Audio API`**。

它裡面放一份「Audio API 動作」的清單，每次觸發時會**隨機挑一個**來執行。**用途：** 想讓重複行為的聲音有變化時很好用——例如角色受傷時，從三、四種慘叫聲裡隨機挑一個播，而不是每次都同一聲。它也提供一次停掉清單內所有聲音的功能。

### 隨機間隔重複播放：Repeat Audio API

元件選單位置：**`0 : SOB/APIs/Repeat Audio API`**。

它會以**隨機的時間間隔**反覆觸發某個動作。你設定間隔的最短與最長秒數，再指定要重複的對象——可以是單一個 Audio API 動作，或一個上面的「隨機播放」元件（兩者擇一）。**用途：** 製造不規律的環境氣氛音，例如「每隔 5 到 12 秒隨機傳來一聲鳥叫或蟲鳴」。提供開始與停止兩個操作，讓你在進出某個區域時開關這個循環。

## 編輯器工具：管理音檔庫

這套工具讓你把專案裡的音檔整理成命名群組，之後就能用名稱來播放（見上方〈兩種指定音檔的方式〉）。

### Audio 視窗

選單位置：**`Braverse > Audio > Audios`**。

這是一個左右雙面板的視窗：

- **左面板** 列出所有群組（例如 `UI`、`Level1`、`Enemy`）。
- **右面板** 編輯目前選到的群組裡的音檔——是一份可以重新排序的清單，每一筆是「自訂名稱 ＋ 對應音檔」的配對。

你在這裡建立群組、加入音檔、替每個音檔取一個好記的名字，這些名字就是日後播放時要用的「音檔名稱」。

### 資料夾批次匯入

如果你已經把一批音檔放在某個資料夾裡，可以用「資料夾轉群組」的工具一次匯入：它會掃描整個資料夾，自動把裡面的音檔建成一個群組並登錄到音檔庫。若已經有同名群組，會先詢問你是否覆寫，避免不小心蓋掉既有設定。**用途：** 聲音很多時，一個一個手動加會很慢，整個資料夾直接匯入快得多。

## 安裝與初次設定

1. **建立聲音管理者。** 新增一個空的 GameObject，掛上聲音管理者元件，並指定它要用的背景音樂播放來源（同一個物件上需要一個 AudioSource）。需要的話，把你的音檔庫也指定上去。
2. **讓它能被自動載入。** 把這個物件做成 prefab，放到專案的 `Resources/SingletonManager/` 資料夾裡。這樣即使某個場景忘了放它，系統第一次需要播聲音時也會自動把它建立出來。它在切換場景時會自動保留，不會被銷毀，所以整個遊戲過程只會有一個、且背景音樂不會在換場景時中斷。請確保該資料夾底下只有這一個 prefab。
3. **（選用）建立音檔庫。** 用上面的 Audio 視窗或資料夾匯入，把聲音整理成群組，之後就能享受用名稱播放的便利。

## 使用前的注意事項

- **背景音樂播放來源是必要的。** 聲音管理者一定要有一個指定好的背景音樂播放來源，所有背景音樂相關的操作都依賴它。
- **音效是「即時建立、播完回收」。** 一般使用完全不必擔心，但若在極短時間內密集播放大量一次性音效，這個建立與回收的動作會很頻繁，效能吃緊的場合要留意。
- **名稱查表打錯時的行為不一致。** 播音效找不到會安靜略過（不出聲、不報錯），播背景音樂找不到則會直接出錯。使用名稱播放前，請確認群組與音檔名稱正確。
- **只能有一個聲音管理者。** 請確保 `Resources/SingletonManager/` 資料夾底下只放一個對應的 prefab，否則自動載入時可能拿到非預期的那一個。
- **編輯器工具的音檔庫路徑是預設好的。** 預設位置在 `Assets/Resources_moved/Audio/`。若你的專案把音檔庫放在別處，需要請工程師調整對應設定，否則編輯器視窗可能找不到你的音檔庫。
- **內附的設定畫面只是範例。** 系統附的音量設定介面是一個示範用的滑桿接法，預設值是隨手填的，實際專案請接到你自己的設定畫面與偏好來源。
