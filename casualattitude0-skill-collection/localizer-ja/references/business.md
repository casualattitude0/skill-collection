## まず三つ決める

敬語のレベルは「丁寧さの量」ではなく**位置関係の表明**。訳し始める前に確定する。

1. **ウチかソトか**（社内／社外）— 最重要。自社側の人間には敬語を使わない（社外に向けて話すとき「弊社の田中が申しました」）。
2. **上下**（相手が上位か同格か下位か）
3. **用件の種類**（依頼・拒否・謝罪・通知・催促）— これが語彙と迂回度を決める

同僚に「ご確認いただけますでしょうか」を使うと、丁寧ではなく**距離を置いた／皮肉**に読まれる。逆に社外顧客に「確認しておいて」は失礼。過剰も不足も同じ失敗。

社内チャット（Slack 等）は敬体でも軽め：「確認お願いします」「〜でお願いできますか」。メールの定型句をチャットに持ち込むと重い。

## 敬語の三層

| | 誰を高めるか | 例 |
|---|---|---|
| **尊敬語** | 相手の行為 | いらっしゃる、ご覧になる、おっしゃる、なさる |
| **謙譲語** | 自分の行為（相手を高める） | 伺う、拝見する、申す、いたす |
| **丁寧語** | 話し方全体 | です、ます、ございます |

### 対照表

| 普通 | 尊敬語（相手） | 謙譲語（自分） |
|------|------|------|
| 見る | ご覧になる | 拝見する |
| 言う | おっしゃる | 申す／申し上げる |
| 行く／来る | いらっしゃる／お越しになる | 伺う／参る |
| 聞く | お聞きになる | 伺う／拝聴する |
| する | なさる | いたす |
| 知っている（事柄） | ご存じ | 存じております |
| 知っている（人） | ご存じ | **存じ上げております** |
| 食べる | 召し上がる | いただく |
| 会う | お会いになる | お目にかかる |
| もらう | お受け取りになる | 頂戴する／賜る |

方向を間違える（自分に尊敬語、相手に謙譲語）のは、非母語者の典型的な破綻。「私が拝見なさいます」のような形は即座に分かる。

## やりがちな敬語事故

### 二重敬語

既に敬語である語に、さらに敬語を重ねる。機械翻訳と非母語者が最も高頻度で踏む。

| ❌ | ✅ |
|---|---|
| お伺いさせていただきます | 伺います |
| ご拝見いたしました | 拝見しました |
| お召し上がりになられる | 召し上がる |
| ご覧になられますか | ご覧になりますか |
| お聞きになられました | お聞きになりました |

### 「させていただく」濫用

成立条件は **①相手の許可がある ②自分が恩恵を受ける**。片方でも欠けると不自然。

| ❌ | ✅ |
|---|---|
| 資料を送付させていただきます | 資料をお送りします |
| ご説明させていただきます | ご説明します |
| 休ませていただきます | 休みます／お休みをいただきます |
| 参加させていただきました | 参加しました（許可を得た文脈なら可） |

正しく効くのは：「ご厚意に甘えて、拝見させていただきました」「お名前を使わせていただきます」。

### そのほか

- 「〜になります」の誤用：変化していないものに使わない。「こちらが資料になります」→「こちらが資料です」
- 「了解しました」は同格・下位向け。上位・社外には「承知しました」「かしこまりました」
- 「ご苦労さま」は上から下。同格・上位には「お疲れさまです」
- 「〜のほう」の緩衝的使用（「資料のほう」）は口語では通るが文書では削る
- 「大丈夫です」は曖昧（Yes とも No とも取れる）。文書では明示する

## メールの定型

日本語ビジネスメールは定型が骨格。定型を崩すと内容以前に落ち着かない。

### 冒頭

- 社外（既知）：`お世話になっております。○○株式会社の△△です。`
- 社外（初回）：`突然のご連絡失礼いたします。○○株式会社の△△と申します。`
- 社内：`お疲れさまです。△△です。`

### 結び

- `ご確認のほど、よろしくお願いいたします。`
- `お手数をおかけしますが、よろしくお願いいたします。`
- `ご不明な点がございましたら、お気軽にお知らせください。`
- `引き続きよろしくお願いいたします。`

### よく使う一文

| 用途 | 表現 |
|------|------|
| 依頼 | `〜していただけますでしょうか。` `〜をお願いできますでしょうか。` |
| 期限を切る | `○日までにご返信いただけますと幸いです。` |
| 添付 | `〜を添付いたしました。ご確認ください。` |
| 感謝 | `早々のご対応、ありがとうございます。` |
| 確認 | `念のため確認させてください。` |
| 転送・共有 | `ご参考までに共有いたします。` |

英語メールの `Dear` `Best regards` を直訳しない。`拝啓／敬具` は正式な書状（紙）用で、日常のメールには重すぎる。

## 断る・催促する・謝る（強度の階梯）

「高情商不著痕跡」が日本語で具体的に何かというと、**この階梯の正しい段を選ぶこと**。柔らかすぎると相手は望みが残っていると読み、硬すぎると関係が切れる。

### 断り（弱 → 強）

1. `前向きに検討いたします。` — **最も弱い。** 「前向きに」は成功確率を上げて聞こえる。実務上はほぼ断りだが、相手には最大限の含みが残る。escalation として使ってはいけない——強めるつもりで「前向きに」を足すと、逆に望みを与える
2. `検討させてください。` — 中立の保留。相手も保留と読む
3. `現状では難しいかと存じます。` — 実質的な拒否。これが標準
4. `今回は見送らせていただきます。` — 明確な拒否、関係は維持
5. `お受けいたしかねます。` / `お断りいたします。` — 明言。強い

階段を上がる ＝ 含みを減らす。1 と 2 の順序を間違えると、断りを固めたつもりで相手を励ますことになる——そして相手は礼儀正しく返信してくるので、失敗したことに気づけない。

`無理です` `できません` は原文がどれだけ直接的でも、そのまま使うと角が立つ。3 か 4 に置き換えるのが通常。ただし**安全・法務・期限に関わる場合は曖昧にしない**——優しさより明確さが要る場面はある。訳者が判断できないときは使用者に確認する。

### 催促（弱 → 強）

1. `念のためご確認まで。`
2. `ご多忙のところ恐れ入りますが、進捗はいかがでしょうか。`
3. `再度のご連絡失礼いたします。○日にお送りした件、ご確認いただけましたでしょうか。`
4. `期日が迫っておりますので、本日中にご返信いただけますようお願いいたします。`

### 謝罪（弱 → 強）

1. `恐れ入ります。` / `失礼いたしました。`
2. `ご迷惑をおかけし、申し訳ございません。`
3. `深くお詫び申し上げます。`
4. `弊社の不備によりご迷惑をおかけしましたこと、心よりお詫び申し上げます。`（原因＋謝罪＋再発防止の三点セット）

謝罪文で責任の所在を訳しながらぼかすのは危険。原文が認めている範囲を超えても、下回ってもいけない。

## クッション言葉

依頼・拒否・指摘の前に置く緩衝句。日本語ビジネス文の必須部品で、これが無いと原文の意図どおりでも冷たく読まれる。

| 用途 | クッション |
|------|------|
| 依頼 | `恐れ入りますが` `お手数をおかけしますが` `ご多忙のところ恐縮ですが` |
| 拒否 | `あいにくですが` `残念ながら` `せっかくのお話ですが` |
| 指摘 | `差し支えなければ` `念のためですが` `私の理解不足かもしれませんが` |
| 反対 | `おっしゃることは理解しておりますが` `一点確認させていただきたいのですが` |

「私の理解不足かもしれませんが」で始まる指摘は、実際には相手の誤りを指摘している——**これが「不著痕跡」の実装**。自分を下げて相手の面子を残しつつ、内容は通す。

過剰に積むと逆効果（一文にひとつ）。

## 社内語・社外語

自称は「社内／社外」では切れない。**文書の種類**で切る。

| 自称 | 使う場面 |
|------|------|
| 弊社 | 特定の相手とのやりとり（メール・書簡・商談）。謙譲 |
| 当社 | プレスリリース・契約書・規約・IR・社内文書。中立フォーマット |
| 小社 | 出版業界のみ。一般語ではない |

**プレスリリースや契約書で「弊社」を使うと、不特定多数に向かって謙遜していることになり、通知文が詫び状のように読める。** business.md の対象にはこの二つが含まれているので、実際に踏む。

| 意味 | 社内向け | 社外向け |
|------|------|------|
| 相手の会社 | — | 貴社・御社（口頭は御社） |
| 自社の人 | 田中さん・田中部長 | 田中（敬称なし） |
| 相手の人 | — | 田中様・田中部長 |

社外に向けて自社の上司を「田中部長がおっしゃいました」と言うのは誤り。「田中が申しました」。この規則は非母語者がほぼ必ず外す。

## UI 文言・サポート文

- ボタン・メニューは体言止めか短い動詞：「保存」「送信」「キャンセル」。「保存します」にしない。
- 見出しは体言止め、本文は敬体。
- エラーメッセージは責めない主語なし文：「パスワードが正しくありません」（×「あなたは間違ったパスワードを入力しました」）。
- 空状態・完了メッセージは簡潔に。英語の陽気な文体（"All done! 🎉"）を直訳すると日本語 UI では軽薄に見える。「完了しました」で足りる。
- 敬体の統一：一箇所だけ常体が混ざるのが典型的な破綻。既存プロダクトがあれば、その表記ルールに合わせるのが最優先——新しく良い訳よりも一貫性が勝つ。
